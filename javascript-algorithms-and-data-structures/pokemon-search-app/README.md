# Pokémon Search App

A web application that allows users to search for Pokémon by name or ID and displays detailed information including stats, types, and images. Built as part of the freeCodeCamp JavaScript Algorithms and Data Structures curriculum.

![Screenshot](./screenshot.png)

## Features

* Search Functionality: Search for any Pokémon by name or ID number
* Comprehensive Stats Display: View HP, Attack, Defense, Special Attack, Special Defense and Speed
* Dynamic Theming: Card background color changes based on Pokémon type(s)
* Responsive Design

## How to Use

1. Enter a Pokémon name (e.g., "Pikachu") or ID number (e.g., "25") in the search field.
1. Click the "Search" button.
1. View the Pokémon's information displayed on the card below.

## Tech Stack

* HTML
* CSS
* JavaScript (Vanilla)

## API Integration

Uses freeCodeCamp's PokéAPI Proxy (https://pokeapi-proxy.freecodecamp.rocks/api/pokemon/) for fetching Pokémon data.
