## Notes
* **Timing:** The projects were all done at different times in the past. The commit history here only reflects when this repo was created, not when the actual projects were done. For a more representative timing of when a project was finished, take a look at the dependencies for the project. This should give you a rough idea.
* **Maintenance:** On the topic of dependencies, these projects are not being actively maintained. If you are planning on running these publicaly, please make sure to take care of the outdated dependencies accordingly.
* **freeCodeCamp Requirements:** At the time each project was made, all requirements by freeCodeCamp were fulfilled. As freeCodeCamp gets regularly updated, there is no guarantee that these project will still in the future be fulfilling all requirements.
* **Approach:** Something to keep in mind is that I wanted to try new things and experiment with these projects as much as possible. For that reason not every project was built in the "most optimal" way. Further details can be found in the project's README.

## Installation & Usage

1. Clone the repo and navigate to the folder of the project or download only the project that you are interested in.
1. In case the project's README provides installation steps follow these to run locally. For simple projects that don't have instructions just open `index.html` in the browser.
